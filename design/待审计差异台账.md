# 待审计差异台账

所有组件当前为设计草案。此台账列出进入实现前必须裁决的共性问题，不能视为已经证明功能完整等价。

| ID | 范围 | 待审计事项 | 设计方向/完成证据 |
|---|---|---|---|
| D001 | 全部 | 文档与运行时代码默认值/类型/版本可能不同 | 以源码+测试+实际复现裁决并记录 |
| D002 | 全部 | 表格行命名转换不等于完整TS声明 | 逐行给React类型；复杂回调、泛型、Vue类型移除 |
| D003 | 双向绑定 | modelValue与change、具名update事件重名 | 值请求和语义事件分离，按事件轨迹定顺序 |
| D004 | 子组件 | 部分目录仅重导出，上级index才是真实实现 | 追踪入口和实例类型，不为同一组件重复建两套状态 |
| D005 | props | 原生HTML属性、type/size/onChange/onSelect冲突 | Omit明确替换，React业务事件保持来源参数 |
| D006 | slots | Vue函数/VNode、插槽优先级与fallback | ReactNode/render函数，逐项验证0/空节点/条件渲染 |
| D007 | ref | Vue ComputedRef/Ref与实例方法混合 | getter/公开handle；不要暴露内部store可变对象 |
| D008 | 服务 | 静态调用无法自然继承任意Context | Provider绑定服务与独立默认宿主明确区分 |
| D009 | 样式 | 原SCSS可能依赖Vue渲染DOM和过渡类 | 先匹配DOM/状态类，再逐场景截图 |
| D010 | 浮层 | Portal事件冒泡、嵌套弹层、shadow DOM | React树和DOM路径联合，验证嵌套关闭与焦点 |
| D011 | 日期 | 源Dayjs/Date/格式/时区/周模型 | 不直接改用Date对象；逐API核对序列化 |
| D012 | 虚拟化 | 变高、overscan、滚动锚、焦点保活 | 源算法/测试审计和大数据浏览器用例 |
| D013 | 图标 | Vue组件无法直接复用 | 核对图形来源及协议，迁移React SVG组件 |
| D014 | 路由 | Vue Router依赖及组件标签 | 宿主导航适配，链接行为和修饰键保持 |
| D015 | 许可 | 源组件、主题、图标、示例版权声明 | MIT保留、来源标记和发布许可证检查 |
| D016 | 历史API | deprecated/beta/后续版本标记 | 保留兼容目标，不删除或误写成React版本 |
| D017 | 测试 | 静态标题不含全部动态用例及断言 | 读取每个测试源文件，建立逐测试映射 |
| D018 | 可访问性 | 来源缺陷与无障碍目标可能冲突 | 原行为和修复差异分别记录并验证 |
| D019 | 数据/异步 | 瞬时状态、异步竞态与卸载取消 | 统一请求版本机制，保留各组件原回调语义 |
| D020 | 源码导出 | 导出目录不是所有命名导出的完整集合 | 审计index.ts及重导出链、类型和服务入口 |

组件特有问题应继续添加：来源文件:行、复现数据、候选方案、最终决策、影响API、测试证据和状态。未核实功能不标记为已支持，未通过验收不使用“100%一致”。
